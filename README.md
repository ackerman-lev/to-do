# To-Do Web App
A simple, lightweight, and beginner-friendly To-Do Web App built using HTML, CSS, JavaScript, and jQuery.


## Project Overview
This application provides an intuitive way for users to manage their daily goals and tasks.

### Features
* **Add Tasks:** Quickly add new tasks to your daily list.
* **Responsive Layout:** Simple and modern interface.
* **Interactive UI:** Smooth splash screen animation on load and dynamic task list updates.

## Built With
* **HTML5:** Page structure and structure of task inputs.
* **CSS3:** Styling, splash screen animations, and custom layout.
* **JavaScript (ES6) & jQuery:** Event handling, DOM manipulation, and dynamic list creation.

## Step-by-Step Local Setup Guide
